KS Stream Deck 1.3.0 makes English the default language and adds a saved German language option for each Stream Deck key. Server owners can select English or German for in-game messages through config.lua.

The release includes English and German installation guides, the standalone FiveM resource, and its companion Stream Deck plugin. Animation names supplied by third-party providers remain in the language configured by those providers.

Download the bundle, update the server resource, and install the included Stream Deck plugin. Existing animation IDs and server bindings remain unchanged.
